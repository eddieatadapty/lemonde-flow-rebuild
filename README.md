# Le Monde Growth Audit

**Live → https://eddieatadapty.github.io/lemonde-flow-rebuild/**

Five ideas to turn more Le Monde users into subscribers, each built into a clickable version of Le Monde's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +8–15% CR to purchase |
| 02 | Make the annual plan the obvious choice | +8–15% ARPU |
| 03 | Let them hear the article before you ask | +5–10% CR to purchase |
| 04 | Put the proof where they hit the wall | +3–6% CR to purchase |
| 05 | Catch the people who close the paywall | +3–7% CR, recovered from closes |

Every price, rating and feature comes from Le Monde's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Le Monde. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
